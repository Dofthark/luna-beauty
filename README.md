# Luna Beauty

A modern and responsive beauty salon website built as a frontend portfolio project.

## About the Project

Luna Beauty is a fictional beauty and wellness studio website designed to provide a clean, elegant and user-friendly experience.

The project demonstrates responsive frontend development, reusable React components, interactive navigation and appointment form functionality.

## Features

- Modern and responsive design
- Smooth section navigation
- Beauty services showcase
- Team section
- Portfolio gallery
- Appointment request form
- DD/MM/YYYY date formatting
- Contact information
- Responsive layout for desktop and mobile devices

## Technologies

- React
- JavaScript
- HTML5
- CSS3
- Vite

## Project Structure

The application is organized using reusable React components and dedicated page sections.

## Appointment Form

The appointment form currently demonstrates frontend functionality. Appointment requests are not stored in a database or sent to a real business.
